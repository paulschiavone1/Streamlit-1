App Description

This app will help users record their everyday spending and see where their money goes. Users will be able to enter expenses with a date, category, and amount, then view them in a table and in simple charts that summarize spending by category and by month.

Intended Users

This app is intended for college students and young adults who want a simple, free way to track a personal budget without using spreadsheets or complicated finance software.

Planned Features
Add a new expense with a date, category, description, and amount
View all saved expenses in a sortable table
Filter expenses by category or date range
Show charts of spending by category and by month
Set a monthly budget and display how much is left
Store expenses in a database so they are saved between sessions
