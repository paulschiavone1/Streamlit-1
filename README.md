Music Recommendation System

Paul Schiavone

App Description

This app will recommend music based on how the user is feeling. Users select their current mood (happy, sad, relaxed, energetic, or focused) and a favorite music genre, and the app generates recommended songs, artists, and playlists to match. It will also display a fun description of the user's music personality based on their choices.

Intended Users

This app is intended for music fans of all ages, especially students and young adults, who want quick, personalized suggestions for what to listen to without searching through streaming apps for the right vibe.

Planned Features
Select a mood (happy, sad, relaxed, energetic, focused)
Choose a music genre
Generate song recommendations (songs, artists, and playlists) based on the mood and genre
Display a fun description of the user's music personality
